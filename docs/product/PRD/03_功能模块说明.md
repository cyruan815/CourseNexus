# 03 核心功能模块说明

本文档为「CourseNexus 课枢 PRD v0.3」的第 03 部分，覆盖标准 PRD 结构中的第 10 章：核心功能模块说明。

本文件只说明各核心功能模块的目标、能力范围、输入输出、核心规则、关联页面和关联数据。页面布局、按钮位置、页面状态和交互细节放在第 11 章；字段字典和数据对象关系放在第 13 章。具体 API 接口细节后续在架构 / 开发文档中说明。

## 10. 核心功能模块说明

### 10.1 课程管理

#### 10.1.1 模块目标

课程管理用于建立学习资料、Agent 问答、学习辅助内容、学习计划和待办任务的基础上下文。用户必须先拥有课程，才能围绕该课程上传资料、发起问答、生成内容和制定学习计划。

#### 10.1.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 创建课程 | 用户在首页打开创建课程弹窗，填写课程名称、简介、教师、学期 | P0 |
| 创建后引导上传 | 创建成功后进入课程详情页并自动打开一次可关闭的上传引导 | P0 |
| 编辑课程 | 修改课程名称、简介、教师、学期 | P1 |
| 删除课程 | 删除不再需要的课程 | P1 |
| 查看课程 | 首页展示当前用户课程 | P0 |
| 进入课程详情 | 点击课程卡片进入课程详情页 | P0 |

#### 10.1.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 课程名称、课程简介、教师、学期 |
| 输出 | Course 记录、课程卡片、课程详情入口 |

#### 10.1.4 核心规则

1. 课程名称必填。
2. 课程必须绑定当前登录用户的 `user_id`。
3. 同一用户下允许存在同名课程，但前端建议通过教师或学期帮助区分。
4. 创建课程弹窗只提交课程基础信息，不承载文件或链接资料输入。
5. 课程创建成功后进入课程详情页，并通过一次性导航状态打开可关闭的上传资料引导。
6. 资料上传是取得 `course_id` 后的独立操作；失败时不回滚课程，用户可在详情页重试。
7. 删除课程前必须二次确认，并提示会影响资料、对话、生成内容、计划和任务。
8. 本期建议使用软删除，避免误删后无法追溯。

#### 10.1.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 首页 | 展示课程列表、打开创建课程弹窗 |
| 创建课程弹窗 | 创建课程基础信息 |
| 编辑课程弹窗 | 修改课程基础信息 |
| 课程详情页 | 查看单门课程学习空间 |

#### 10.1.6 关联数据

| 数据对象 | 说明 |
|---|---|
| Course | 课程基础信息 |
| CourseMaterial | 课程创建后从详情页资料工作台独立上传创建 |
| StudyPlan | 删除课程时需要处理关联计划 |
| Conversation | 删除课程时需要处理关联对话 |
| AIGeneratedContent | 删除课程时需要处理关联生成内容 |

### 10.2 课程资料管理

#### 10.2.1 模块目标

课程资料管理用于集中保存课程学习材料，并为 Agent 问答、学习辅助生成、学习计划生成和任务执行提供资料上下文。

#### 10.2.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 上传文件 | 支持在课程详情页资料工作台上传文件 | P0 |
| 添加链接 | 已停止支持：不再提供链接资料新增入口；历史链接记录仅保留查看与删除 | 不适用 |
| 一级目录分类 | 支持用户自定义一级目录管理资料 | P1 |
| 资料列表 | 展示课程下资料、类型、上传时间、解析状态 | P0 |
| 重命名资料 | 修改用户可见资料名称，不改变原文件和解析结果 | P1 |
| 资料解析 | 上传后异步解析文本、页码或页序号、片段 | P0 |
| 资料索引 | 解析成功后建立可检索索引 | P0 |
| 资料预览 | 支持查看 PDF、PPT、图片、文本等资料内容 | P1 |
| 重试解析 | 解析失败后支持重试 | P0 |
| 删除资料 | 删除不再需要的资料 | P1 |

#### 10.2.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 文件、链接、一级目录、course_id、material_id |
| 输出 | CourseMaterial、MaterialChunk、parse_status、资料预览内容、可检索索引 |

#### 10.2.4 核心规则

1. 资料必须绑定一门课程，课程必须属于当前用户。
2. 支持文件类型包括 PDF、PPT/PPTX、Word、Markdown、图片和纯文本；链接资料不再提供新增入口。
3. 本期允许同一课程下存在同名资料，展示时用上传时间、文件类型或一级目录区分。
4. 上传成功后进入 `uploaded` 或 `parsing` 状态。
5. 解析成功后进入 `parsed` 状态，可用于问答、学习辅助生成和计划生成。
6. 解析失败后进入 `parse_failed` 状态，不参与检索，允许用户重试。
7. 图片可上传；若 OCR 无法提取文本，则不可作为可检索资料。
8. PDF 优先使用真实页码；无法识别时使用页序号。
9. PPT 使用幻灯片顺序作为页序号。
10. Word、Markdown、Text 优先按标题或段落切分，页码可为空。
11. 删除资料后，不再用于新的问答、生成和计划。
12. 重命名资料只改变展示名称，不改变原文件、解析状态、切片、索引和历史引用快照。

#### 10.2.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 课程详情页 | 资料管理主入口 |
| 资料上传入口 | 上传文件 |
| 资料预览视图 | 查看资料内容 |
| 计划学习执行页 | 查看任务关联资料 |

#### 10.2.6 关联数据

| 数据对象 | 说明 |
|---|---|
| CourseMaterial | 资料记录 |
| MaterialFolder | 用户自定义一级目录 |
| MaterialChunk | 解析后的可检索片段 |
| SourceCitation | 引用来源依赖资料片段 |

### 10.3 Agent 问答

#### 10.3.1 模块目标

Agent 问答用于让用户围绕课程资料进行自然语言提问，并获得带引用来源的回答。该模块强调资料上下文、来源可追溯和连续追问能力。

#### 10.3.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 资料范围选择 | 使用整门课程，或选择单个资料、多个资料；一级目录仅用于归类 | P0 |
| 发送问题 | 用户输入自然语言问题 | P0 |
| 资料检索 | 根据问题检索 MaterialChunk | P0 |
| 生成回答 | Agent 基于资料片段生成回答 | P0 |
| 引用来源展示 | 展示资料名、页码或页序号、命中文本片段 | P0 |
| 通用知识补充 | 资料无命中时给出明确提示并补充说明 | P0 |
| 连续追问 | 支持同一会话下连续提问 | P1 |
| 保存为笔记 | 将单轮回答保存为笔记类 AI 生成内容 | P1 |

#### 10.3.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | course_id、material_scope、conversation_id、question |
| 输出 | answer、conversation_id、message_id、source_citations、answer_type |

#### 10.3.4 核心规则

1. 用户未选择资料范围时，默认使用当前课程下全部 `parsed` 资料。
2. 用户选择一个或多个具体资料时，只在指定资料范围内检索；不能选择整个一级目录。
3. 有资料依据时，回答必须尽量基于课程资料。
4. 引用来源至少包含资料名、页码或页序号、命中文本片段。
5. 引用来源必须结构化保存，不只拼接在回答正文中。
6. 资料无命中时，回答开头必须提示“当前课程资料中未找到直接答案”。
7. 保存为笔记统一写入 `AIGeneratedContent.content_type = note`，不单独建 Note 对象。
8. 连续追问需要携带当前 `conversation_id` 和必要上下文。

#### 10.3.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 课程详情页 | 课程问答主入口 |
| 计划学习执行页 | 当前任务上下文问答 |
| 资料预览视图 | 点击引用来源时打开资料定位 |

#### 10.3.6 关联数据

| 数据对象 | 说明 |
|---|---|
| Conversation | 一组课程问答会话 |
| Message | 用户问题和 Agent 回答 |
| MaterialChunk | 被检索和引用的资料片段 |
| SourceCitation | 回答引用来源 |
| AIGeneratedContent | 保存为笔记时创建记录 |

### 10.4 课程自测 Quiz

#### 10.4.1 模块目标

课程自测 Quiz 用于基于课程资料生成自测题，帮助用户检验对知识点的掌握情况。

#### 10.4.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 生成课程自测 Quiz | 基于选定资料范围生成题目 | P0 |
| 查看题目 | 展示题干、题型和选项 | P0 |
| 查看答案 | 展示正确答案 | P0 |
| 查看解析 | 展示答案解析 | P0 |
| 查看生成资料范围 | 展示本次实际参与生成的资料 | P0 |
| 保存结果 | 保存到课程 AI 生成内容中 | P0 |

#### 10.4.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | course_id、material_scope、题型偏好、题量 |
| 输出 | question_type、question_text、options、correct_answer、explanation；顶层返回实际生成资料范围 |

#### 10.4.4 核心规则

1. 课程自测 Quiz 必须基于用户选择的资料范围生成。
2. 题目应尽量覆盖资料范围内的核心知识点。
3. 选择题必须包含选项和正确答案。
4. 每道题应提供答案解析；V1 不承诺课程自测 Quiz 的逐题引用，详情页展示实际生成资料范围。
5. 课程自测 Quiz 结果保存为 AIGeneratedContent，可后续查看。
6. 计划执行页中的任务测试题与课程详情页生成的课程自测 Quiz 不是同一入口；任务测试题属于任务上下文下的按需生成内容。

#### 10.4.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 课程详情页 | 课程自测 Quiz 生成入口 |
| AI 生成内容列表 / 历史记录区 | 查看生成记录或结果 |
| 课程自测 Quiz 页面 | 展示题目、答案、解析和实际生成资料范围 |

#### 10.4.6 关联数据

| 数据对象 | 说明 |
|---|---|
| AIGeneratedContent | 保存课程自测 Quiz 结果 |
| CourseMaterial | 题目生成依据；实际使用的资料名快照保存在 `material_scope_json.source_materials` |

### 10.5 Flashcard

#### 10.5.1 模块目标

Flashcard 用于将课程资料中的概念、公式、定义、易混点转化为记忆卡片，帮助用户快速复习和记忆。

#### 10.5.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 生成 Flashcard | 基于资料范围生成卡片 | P0 |
| 查看卡片正面 | 展示问题、概念或提示 | P0 |
| 翻转卡片 | 查看答案、解释或示例 | P0 |
| 切换卡片 | 在卡片间前后切换 | P0 |
| 标记掌握状态 | 标记已掌握或待复习 | P1 |
| 查看生成资料范围 | 查看本次实际参与生成的资料 | P0 |

#### 10.5.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | course_id、material_scope、卡片数量 |
| 输出 | front、back、tags、mastery_status；顶层返回实际生成资料范围 |

#### 10.5.4 核心规则

1. Flashcard 应优先生成适合记忆的短内容。
2. 卡片正面宜为概念名、问题或提示；背面宜为解释、答案或例子。
3. V1 不承诺逐卡引用；详情页统一展示实际生成资料范围。
4. 本期不做复杂记忆曲线和间隔重复算法。
5. 结果保存为 AIGeneratedContent，可后续查看。

#### 10.5.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 课程详情页 | Flashcard 生成入口 |
| AI 生成内容列表 / 历史记录区 | 查看生成记录或结果 |
| Flashcard 页面 | 展示和翻转卡片 |

#### 10.5.6 关联数据

| 数据对象 | 说明 |
|---|---|
| AIGeneratedContent | 保存 Flashcard 结果 |
| CourseMaterial | 卡片生成依据；实际使用的资料名快照保存在 `material_scope_json.source_materials` |

### 10.6 Mindmap

#### 10.6.1 模块目标

Mindmap 用于将课程资料整理为知识结构图，帮助用户理解知识点之间的层级和关系。

#### 10.6.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 生成 Mindmap | 基于资料范围生成结构图 | P0 |
| 展示节点 | 展示知识节点 | P0 |
| 展示层级关系 | 展示父子层级和关联边 | P0 |
| 展开 / 收起节点 | 支持查看局部结构 | P1 |
| 查看生成资料范围 | 展示本次实际参与生成的资料 | P0 |
| 保存结果 | 保存结构化结果 | P0 |

#### 10.6.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | course_id、material_scope、中心主题 |
| 输出 | root_node、nodes、edges；顶层返回实际生成资料范围 |

#### 10.6.4 核心规则

1. Mindmap 结果必须具备结构化节点和关系。
2. 后端可返回 JSON 结构，前端负责渲染为图形。
3. V1 不承诺逐节点引用；详情页统一展示实际生成资料范围。
4. 生成结果保存为 AIGeneratedContent，可再次查看。
5. 若资料内容过少，可生成简单结构并提示资料不足。

#### 10.6.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 课程详情页 | Mindmap 生成入口 |
| AI 生成内容列表 / 历史记录区 | 查看生成记录或结果 |
| Mindmap 页面 | 展示结构图 |

#### 10.6.6 关联数据

| 数据对象 | 说明 |
|---|---|
| AIGeneratedContent | 保存 Mindmap 结果 |
| CourseMaterial | 结构图生成依据；实际使用的资料名快照保存在 `material_scope_json.source_materials` |

### 10.7 复习提纲

#### 10.7.1 模块目标

复习提纲用于将课程资料整理为章节化复习路径，帮助用户建立复习框架和复习顺序。

#### 10.7.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 生成复习提纲 | 基于资料范围生成章节化提纲 | P0 |
| 展示章节结构 | 展示一级、二级、三级内容 | P0 |
| 展示重点说明 | 标出重点知识点和复习建议 | P0 |
| 查看生成资料范围 | 展示本次实际参与生成的资料 | P0 |
| 保存结果 | 保存到课程 AI 生成内容中 | P0 |

#### 10.7.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | course_id、material_scope、复习目标 |

#### 10.7.6 关联数据

| 数据对象 | 说明 |
|---|---|

| CourseMaterial | 知识点生成依据；实际使用的资料名快照保存在 `material_scope_json.source_materials` |

### 10.9 学习计划

#### 10.9.1 模块目标

学习计划用于将用户的自然语言学习目标转化为可执行的单课程计划、阶段安排、每日一级任务和二级任务。

#### 10.9.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 自然语言目标输入 | 用户输入学习目标 | P0 |
| 配置自动回填 | 解析课程、资料范围、截止时间、每日学习时间、偏好 | P0 |
| 手动调整配置 | 用户修改系统解析结果 | P0 |
| 生成计划预览 | 生成阶段安排和每日任务 | P0 |
| 保存计划 | 用户确认后保存为正式计划 | P0 |
| 生成一级任务 | 生成每日学习主题 | P0 |
| 生成二级任务 | 生成具体知识点学习或任务测试 | P0 |
| 同步待办和日历 | 保存后同步本课程计划学习模式日历、首页今日待办和首页大日历 | P0 |
| 编辑 / 重新生成计划 | 在课程详情页或本课程计划学习模式日历中基于已有计划调整或重新生成 | P1 |
| 删除计划 | 删除不再需要的计划 | P1 |

#### 10.9.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | goal_text、course_id、material_scope、start_date、end_date、daily_available_minutes、preference |
| 输出 | StudyPlan、StudyTask、StudySubTask、每日知识点、关联资料、计划预览 |

#### 10.9.4 核心规则

1. 本期学习计划为单课程计划，一个 StudyPlan 只能绑定一个 `course_id`。
2. 用户需要规划多门课程时，应分别创建多个单课程计划。
3. 首页今日待办和首页大日历合并展示多个单课程计划的任务。
4. 本期不做多课程冲突检测和智能重排。
5. 自然语言解析结果只做配置回填，最终以用户确认或修改后的配置为准。
6. 计划生成阶段只生成计划和任务，不提前生成今日讲义、任务测试题或学习笔记。
7. 每日任务包含一级任务和二级任务；一级任务表示学习主题，二级任务表示具体知识点学习或测试。
8. 测试类二级任务可以作为当天最后一个任务，但不是每天强制必须有。
9. 用户确认保存后，计划和任务进入本课程计划学习模式日历，并同步到首页今日待办和首页大日历。
10. 删除计划需要处理关联未完成任务，建议软删除或状态标记。
11. 首页今日待办和首页大日历只负责查看与跳转，不提供创建、编辑或重新生成学习计划入口。

#### 10.9.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 学习计划页 | 计划生成和保存主入口 |
| 课程详情页 | 为当前课程制定计划入口 |
| 本课程计划学习模式日历 | 展示当前课程计划日程，并进入当日知识点列表 |
| 首页 - 今日待办区域 | 展示计划生成的今日任务 |
| 首页大日历页 | 按日期聚合展示所有课程计划任务摘要 |
| 全局当日待办弹窗 | 按课程分组展示当天任务并跳转 |
| 计划学习执行页 | 执行计划下的任务 |

#### 10.9.6 关联数据

| 数据对象 | 说明 |
|---|---|
| StudyPlan | 学习计划 |
| StudyTask | 每日一级任务 |
| StudySubTask | 二级学习任务或任务测试 |
| Course | 计划绑定课程 |
| CourseMaterial | 计划关联资料 |

### 10.10 个人中心

#### 10.10.1 模块目标

个人中心用于管理用户基础资料、修改密码，并展示用户学习完成情况。本期学习打卡颜色由当日二级任务完成比例决定。

#### 10.10.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 查看账号信息 | 展示账号、昵称、头像等基础信息 | P0 |
| 修改昵称 | 用户修改个人昵称 | P0 |
| 修改头像 | 用户上传头像并更新 | P1 |
| 修改密码 | 用户输入旧密码和新密码完成修改 | P0 |
| 查看学习打卡颜色 | 展示当天或历史日期的学习打卡颜色 | P0 |
| 学习完成比例 | 按当日二级任务完成比例计算学习打卡颜色深浅 | P0 |

#### 10.10.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | nickname、avatar_file、old_password、new_password、date |
| 输出 | User、CheckinRecord、completion_ratio、color_level |

#### 10.10.4 核心规则

1. 用户只能查看和修改自己的个人资料。
2. 修改密码需要校验旧密码。
3. 修改密码成功后建议使当前登录态失效，并要求用户重新登录。
4. 学习打卡颜色不是用户手动点击生成，而是根据当日二级任务完成比例展示颜色深浅。
5. 同一用户同一自然日最多一条 CheckinRecord。
6. `completion_ratio = completed_subtask_count / total_subtask_count`。
7. 当日完成比例越高，学习打卡颜色越深；完成比例较低时使用同色系浅色。
8. 当天没有二级任务时，可展示无任务或未形成打卡状态。
9. 用户完成或取消完成二级任务后，应重新计算当天学习打卡颜色。

#### 10.10.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 个人中心页 | 个人资料、密码和打卡展示 |
| 计划学习执行页 | 二级任务完成后影响打卡比例 |
| 首页 - 今日待办区域 | 今日任务完成情况影响打卡比例 |

#### 10.10.6 关联数据

| 数据对象 | 说明 |
|---|---|
| User | 用户账号与基础资料，包含昵称和头像字段 |
| CheckinRecord | 学习完成记录，驱动学习打卡颜色展示 |
| StudySubTask | 学习完成比例计算依据 |

### 10.11 对话记录

#### 10.11.1 模块目标

对话记录用于保存用户在课程详情页或计划学习执行页中的提问和 Agent 回答，支持用户回看上下文、连续追问和保存回答。

#### 10.11.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 创建会话 | 首次提问时创建 Conversation | P0 |
| 保存用户问题 | 保存用户输入内容 | P0 |
| 保存 Agent 回答 | 保存回答正文和状态 | P0 |
| 保存引用来源 | 保存回答对应 SourceCitation | P0 |
| 连续追问 | 在同一 conversation_id 下继续提问 | P1 |
| 查看历史记录 | 按课程查看对话记录 | P1 |
| 保存为笔记 | 将回答保存为 AI 生成内容记录 | P1 |

#### 10.11.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | course_id、conversation_id、question、answer、source_citations |
| 输出 | Conversation、Message、SourceCitation、AIGeneratedContent note |

#### 10.11.4 核心规则

1. 对话记录必须归属于课程，并间接归属于用户。
2. 用户问题和 Agent 回答都需要保存。
3. 回答生成失败时可记录失败状态，但不应伪装为正常回答。
4. 引用来源与回答结构化关联。
5. 保存为笔记时创建 AIGeneratedContent，`content_type = note`。
6. 用户只能查看自己课程下的对话记录。

#### 10.11.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 课程详情页 | 课程问答对话记录 |
| 计划学习执行页 | 当前任务问答记录 |
| AI 生成内容列表 / 历史记录区 | 保存为笔记后在列表中可查看 |

#### 10.11.6 关联数据

| 数据对象 | 说明 |
|---|---|
| Conversation | 会话 |
| Message | 消息 |
| SourceCitation | 引用来源 |
| AIGeneratedContent | 保存为笔记 |

### 10.12 待办任务

#### 10.12.1 模块目标

待办任务用于承接学习计划生成后的每日任务，并支撑本课程计划学习模式日历、首页今日待办、首页大日历、全局当日待办弹窗和计划学习执行页。

#### 10.12.2 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 今日待办展示 | 首页展示当天任务 | P0 |
| 本课程计划学习模式日历 | 在课程内查看当前课程的计划日程 | P0 |
| 首页大日历摘要 | 日期格展示课程数量、任务数量和完成摘要 | P0 |
| 全局当日待办弹窗 | 点击日期后按课程分组查看当天任务 | P0 |
| 课程知识点展开 | 课程分组下的知识点 / 二级任务可展开或折叠 | P0 |
| 进入执行页 | 点击二级任务进入计划学习执行页 | P0 |
| 完成二级任务 | 用户勾选或取消二级任务完成状态 | P0 |
| 自动汇总一级任务 | 根据二级任务完成情况计算一级任务状态 | P0 |
| 同步状态 | 本课程计划学习模式日历、首页今日待办、首页大日历、弹窗、执行页状态一致 | P0 |

#### 10.12.3 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | plan_id、task_id、subtask_id、date、completion_status |
| 输出 | StudyTask、StudySubTask、任务完成状态、月历摘要、当日待办 |

#### 10.12.4 核心规则

1. 一级任务表示某天的学习主题。
2. 二级任务表示具体知识点学习或任务测试。
3. 首页今日待办展示当天任务，可进入计划学习执行页。
4. 本课程计划学习模式日历只展示当前课程的计划日程。
5. 首页大日历日期格只展示课程数量、任务数量和完成摘要，不展示完整二级任务详情。
6. 点击首页大日历日期后打开全局当日待办弹窗，按课程分组展示当天日程。
7. 用户展开某课程后查看该课程当天知识点 / 二级任务列表。
8. 首页今日待办和首页大日历只负责查看与跳转，不提供学习计划创建、编辑或重新生成入口。
9. 二级任务有独立完成状态。
10. 一级任务状态自动汇总：全部未完成为未开始，部分完成为进行中，全部完成为已完成。
11. 二级任务完成情况会影响个人中心学习打卡颜色。

#### 10.12.5 关联页面

| 页面 / 区域 | 关系 |
|---|---|
| 首页 - 今日待办区域 | 展示当天任务 |
| 本课程计划学习模式日历 | 展示当前课程计划日程 |
| 首页大日历页 | 聚合展示所有课程日期任务摘要 |
| 全局当日待办弹窗 | 按课程分组展示当天任务 |
| 计划学习执行页 | 执行具体二级任务 |
| 个人中心页 | 展示任务完成比例对应的学习打卡颜色 |

#### 10.12.6 关联数据

| 数据对象 | 说明 |
|---|---|
| StudyPlan | 任务所属计划 |
| StudyTask | 一级任务 |
| StudySubTask | 二级任务 |
| AIGeneratedContent | 讲义和任务测试题等任务生成内容，使用 `content_type = handout` 或 `task_test` 并关联二级任务 |
| CheckinRecord | 根据二级任务完成比例更新 |
