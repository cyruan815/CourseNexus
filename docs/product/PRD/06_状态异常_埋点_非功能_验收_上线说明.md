# 06 状态异常_埋点_非功能_验收_上线说明

本文档对应《CourseNexus 课枢 PRD》的第 14-18 章，集中说明状态、异常、边界情况、埋点统计、非功能需求、验收标准和上线说明。

本文件用于产品验收、前后端联调、测试用例拆解和上线前检查。页面交互细节见 `04_页面与交互说明.md`，Agent 与字段规则见 `05_Agent规则_字段与数据规则.md`。

## 14. 状态、异常与边界情况

### 14.1 页面状态

| 状态 | 适用范围 | 展示规则 | 用户可操作 |
|---|---|---|---|
| `loading` | 首页、课程详情页、首页大日历页、个人中心页等 | 展示加载态，不应出现空白页 | 暂不可操作核心按钮 |
| `success` | 所有页面 | 正常展示数据和操作入口 | 可操作 |
| `empty` | 课程列表、资料列表、今日待办、首页大日历月份、本课程计划学习模式日历、生成内容列表 | 展示空状态和下一步入口 | 可执行创建、上传、返回等操作 |
| `error` | 数据加载失败、权限失败、服务异常 | 展示错误提示和重试入口 | 可重试或返回 |
| `disabled` | 无权限、登录失效、按钮 loading 中 | 按钮置灰或页面跳转登录 | 不可执行受限操作 |
| `partial_success` | 创建课程成功但资料上传/解析部分失败 | 展示课程已创建，失败资料可重试 | 可进入课程详情并重试资料 |

页面状态规则：

1. 页面加载失败不能影响用户返回上一页或重新登录。
2. 局部模块加载失败时，不应导致整个页面不可用。例如首页今日待办加载失败，不影响课程列表展示。
3. 弹窗提交失败时，应保留用户已输入内容。
4. 首页大日历页无任务时应展示空日历，而不是错误态。
5. 全局当日待办弹窗无任务时展示“当日暂无任务”，不是异常。

### 14.2 操作状态

| 操作 | 默认态 | 处理中 | 成功后 | 失败后 | 重复点击规则 |
|---|---|---|---|---|---|
| 登录 | 可点击 | 登录中，按钮禁用 | 进入首页 | 保留账号，提示失败 | 禁用重复点击 |
| 注册 | 可点击 | 注册中，按钮禁用 | 注册成功后自动登录并进入首页 | 保留输入，提示失败 | 禁用重复点击 |
| 创建课程 | 可点击 | 创建中，按钮禁用 | 进入课程详情页 | 保留表单 | 幂等，避免重复课程 |
| 上传资料 | 可点击 | 上传中 | 展示解析中 | 标记失败，可重试 | 同批次上传中禁用重复提交 |
| 发送问题 | 可点击 | 生成中 | 展示回答与引用来源 | 保留问题，可重试 | 禁用重复点击 |
| 生成学习辅助内容 | 可点击 | 生成中 | 展示生成结果 | 可重试 | 同一请求防重复 |
| 解析自然语言目标 | 可点击 | 解析中 | 回填配置 | 可手动补充或重试 | 禁用重复点击 |
| 保存计划 | 可点击 | 保存中 | 同步任务到本课程计划学习模式日历、首页今日待办和首页大日历 | 保留预览，可重试 | 幂等，避免重复计划 |
| 完成二级任务 | 可点击 | 更新中 | 更新任务状态和学习完成比例 | 可重试 | 幂等 |
| 导出 PDF | 可点击 | 导出中 | 下载或保存 PDF | 可重试 | 导出中禁用 |
| 修改密码 | 可点击 | 保存中 | 提示成功或重新登录 | 保留输入并提示失败 | 禁用重复点击 |

### 14.3 生成状态

| 生成对象 | 状态 | 说明 |
|---|---|---|
| 资料解析 | `uploaded` | 文件已上传，尚未解析 |
| 资料解析 | `parsing` | 正在抽取文本、切片、索引 |
| 资料解析 | `parsed` | 解析成功，可进入检索上下文 |
| 资料解析 | `parse_failed` | 解析失败，可重试 |
| Agent 回答 | `generating` | 正在生成回答 |
| Agent 回答 | `success` | 回答生成成功 |
| Agent 回答 | `failed` | 回答生成失败 |
| AI 生成内容 | `pending` | 等待生成 |
| AI 生成内容 | `generating` | 生成中 |
| AI 生成内容 | `success` | 生成成功 |
| AI 生成内容 | `failed` | 生成失败 |
| 学习计划 | `draft` | 已生成预览但未保存 |
| 学习计划 | `active` | 已保存并生效 |
| 学习计划 | `completed` | 计划任务全部完成 |
| 学习计划 | `deleted` | 已删除或隐藏 |
| 一级/二级任务 | `not_started` | 未开始 |
| 一级/二级任务 | `in_progress` | 部分进行中 |
| 一级/二级任务 | `completed` | 已完成 |

状态流转规则：

1. 资料只有 `parsed` 后才能进入 Agent 检索范围。
2. 一级任务状态由下属二级任务状态自动计算。
3. 二级任务完成后，应更新本课程计划学习模式日历、首页今日待办、首页大日历任务状态和个人中心学习打卡颜色。
4. 计划保存时只生成任务结构，不提前生成今日讲义和任务测试题正文。
5. 今日讲义和任务测试题进入对应任务后按需生成。

### 14.4 异常处理表

| 异常场景 | 触发条件 | 系统处理 | 用户提示 |
|---|---|---|---|
| 未登录访问 | 无有效登录态 | 跳转登录页 | 请先登录 |
| 登录失效 | token 过期或账号状态异常 | 清理登录态，跳转登录 | 登录已失效，请重新登录 |
| 无权限访问课程 | 用户访问非本人课程 | 阻止访问 | 无权访问该课程 |
| 课程创建失败 | 后端保存失败 | 保留表单，允许重试 | 创建失败，请重试 |
| 课程创建成功但资料失败 | 课程创建成功，资料上传/解析失败 | 进入课程详情，资料标记失败 | 课程已创建，部分资料处理失败 |
| 资料格式不支持 | 上传不支持格式 | 拒绝上传 | 当前文件格式暂不支持 |
| 文件过大 | 超过上传限制 | 拒绝上传 | 文件超过大小限制 |
| 链接抓取失败 | 链接不可访问或解析失败 | 保存链接记录，标记解析失败 | 链接解析失败，可重试 |
| 图片 OCR 不可用 | 图片无法抽取文字 | 资料可保留但不可检索 | 图片暂无法检索文本 |
| Agent 无资料命中 | 检索不到相关片段 | 返回 no_source 答案 | 当前课程资料中未找到直接答案 |
| Agent 生成失败 | 模型或生成服务失败 | 保存失败状态，允许重试 | 回答生成失败，请重试 |
| 引用定位失败 | 页码/切片无法定位 | 不打开 PDF 第一页，展示保存的引用片段 | 暂时无法定位到原文 |
| 引用来源失效 | 资料删除、无权限或原文件不可用 | 保留历史引用快照 | 来源不可用 |
| 生成内容失败 | 课程自测 Quiz/Flashcard/Mindmap 等生成失败 | 保留失败状态，允许重试 | 生成失败，请重试 |
| 自然语言解析失败 | 无法解析目标 | 保留输入，允许手动配置 | 未能完整解析，请手动补充 |
| 保存计划失败 | 后端保存失败 | 保留计划预览 | 保存失败，请重试 |
| 首页大日历加载失败 | 月任务查询失败 | 显示重试入口 | 日历任务加载失败 |
| 全局当日待办为空 | 当天无任务 | 展示空状态 | 当日暂无任务 |
| 本课程计划不存在 | 计划被删除或无权限 | 返回课程详情页 | 计划不存在或已删除 |
| 讲义生成失败 | 任务讲义生成失败 | 允许重试 | 今日讲义生成失败 |
| 任务测试题生成失败 | 任务测试题生成失败 | 允许重试 | 任务测试题生成失败 |
| PDF 导出失败 | 导出服务失败 | 不影响内容查看 | 导出失败，请重试 |
| 学习完成记录数据计算失败 | 完成比例统计失败 | 保留任务状态，学习打卡颜色显示重试 | 学习完成数据加载失败 |

埋点规则：

1. 所有埋点不得上传密码、原始文件内容、完整用户问题正文等敏感内容。
2. 失败事件必须带 `error_code`，便于排查。
3. 生成类事件应记录耗时 `duration_ms`。
4. 引用来源点击事件应区分来自 Agent 回答还是学习辅助生成内容。

### 15.2 核心指标

| 指标 | 统计口径 | 用途 |
|---|---|---|
| 注册用户数 | 注册成功用户数 | 观察用户增长 |
| 登录成功率 | 登录成功次数 / 登录提交次数 | 观察账号系统稳定性 |
| 课程创建数 | 创建成功课程数 | 观察核心使用量 |
| 课程创建成功率 | 创建成功次数 / 创建提交次数 | 观察课程创建链路 |
| 资料上传成功率 | 上传成功文件数 / 上传文件数 | 观察资料上传稳定性 |
| 资料解析成功率 | 解析成功资料数 / 开始解析资料数 | 观察解析能力 |
| Agent 问答成功率 | 回答成功次数 / 提问次数 | 观察 Agent 可用性 |
| Agent 有引用回答占比 | `citation_count > 0` 的回答数 / 回答成功数 | 观察资料 grounded 程度 |
| 引用来源点击率 | 引用点击次数 / 展示引用回答次数 | 观察用户是否追溯来源 |
| 学习辅助生成成功率 | 生成成功次数 / 生成提交次数 | 观察生成稳定性 |
| 学习计划保存率 | 保存成功计划数 / 计划预览生成数 | 观察计划转化 |
| 二级任务完成率 | 已完成二级任务数 / 生成二级任务数 | 观察学习执行 |
| 每日任务完成比例 | 当日已完成二级任务数 / 当日二级任务总数 | 驱动学习打卡颜色 |
| PDF 导出成功率 | 导出成功次数 / 导出点击次数 | 观察导出稳定性 |

### 15.3 数据统计口径

1. 用户维度统计以 `user_id` 为准。
2. 课程维度统计以 `course_id` 为准。
3. 学习计划本期以单课程计划为单位统计，一个 `StudyPlan` 只对应一个 `course_id`。
4. 首页今日待办和首页大日历的任务统计可合并多个单课程计划。
5. 每日学习完成比例按自然日和用户维度统计，公式为 `completed_subtask_count / total_subtask_count`。
6. 当日无二级任务时，不计入任务完成率分母，学习打卡颜色可展示无任务状态。
7. 生成失败不计入生成成功数，但计入生成提交数。
8. 资料解析失败计入解析失败，不计入可检索资料数。

## 16. 非功能需求

### 16.1 性能要求

| 场景 | 要求 |
|---|---|
| 首页加载 | 常规数据量下 3 秒内展示主要内容 |
| 课程详情页加载 | 3 秒内展示课程资料列表和问答区域骨架 |
| 首页大日历加载 | 3 秒内展示当前月份任务摘要 |
| 资料上传 | 上传过程展示进度或处理中状态 |
| 资料解析 | 支持异步解析，不阻塞用户继续使用课程 |
| Agent 问答 | 生成中应有明确反馈，长耗时允许异步或流式展示 |
| PDF 导出 | 导出中展示 loading，失败可重试 |

### 16.2 兼容性要求

1. 本期优先支持桌面端浏览器使用。
2. 常见浏览器包括 Chrome、Edge、Safari 的近两年主流版本。
3. 页面宽度不足时，三栏结构应能降级为可切换布局或上下布局，避免内容重叠。
4. PDF、PPT、图片、文本等资料预览能力以浏览器和后端解析能力为准。
5. Mermaid 流程图仅作为 PRD 表达，不要求系统运行时渲染。

### 16.3 稳定性要求

1. 生成类任务失败不应导致页面崩溃。
2. 资料上传失败不应影响已创建课程。
3. 资料解析失败不应影响其他资料检索。
4. 单个学习辅助生成失败不应影响其他学习辅助功能。
5. 任务完成状态更新失败时，不应误更新学习完成比例。
6. 后端应记录关键错误日志，至少覆盖上传、解析、生成、保存计划、导出 PDF。

### 16.4 可用性要求

1. 所有核心操作必须有明确反馈：成功、失败、loading、空状态。
2. 弹窗关闭、返回、取消操作应符合用户预期。
3. 全局当日待办弹窗必须按课程分组展示，展开课程后再展示知识点 / 二级任务。
4. 首页大日历日期格只展示简略任务摘要，避免信息过载。
5. 引用来源必须方便点击和定位。
6. 计划学习执行页左侧只展示今日学习任务，避免用户被完整计划树干扰。
7. 资料预览由用户选择分屏或小窗，不使用固定右侧抽屉。

### 16.5 数据一致性要求

| 场景 | 一致性要求 |
|---|---|
| 创建课程 + 后续资料上传 | 课程先独立创建；详情页上传或解析失败不回滚课程，资料单独反馈失败 |
| 删除课程 | 课程及其资料、对话、生成内容、计划和任务对用户隐藏 |
| 删除资料 | 资料从检索范围移除，历史引用保留快照并提示资料可能已删除 |
| 保存计划 | 必须同时生成计划、一级任务、二级任务；失败时不能出现半保存的前端可见计划 |
| 完成二级任务 | 更新二级任务状态、自动计算一级任务状态、更新学习完成记录 |
| 学习完成记录 | 同一用户同一天最多一条，重复请求幂等 |
| 保存为笔记 | 统一写入 `AIGeneratedContent.content_type = note` |
| 引用来源 | 必须保存资料名、页码/页序号、命中文本片段 |

## 17. 验收标准

### 17.1 页面验收标准

| 页面 / 模块 | 验收标准 |
|---|---|
| 登录页 | 用户可使用账号密码登录；错误账号密码有提示 |
| 注册页 | 用户可创建账号；重复账号有提示 |
| 首页 | 展示课程列表、今日待办局部模块、首页大日历入口、个人中心入口 |
| 创建课程弹窗 | 可创建课程基础信息；成功后进入课程详情页并打开一次可关闭的上传引导 |
| 课程详情页 | 三栏结构可用：资料区、Agent 问答区、功能入口区 |
| 资料预览视图 | PDF 有可靠页码时定位对应页；Text / Markdown 展示解析片段；未知页码不默认打开第一页；失效来源保留快照并明确提示 |
| 学习计划页 | 自然语言目标可解析并回填配置；用户可调整并保存 |
| 首页大日历页 | 只有大尺寸日历；没有默认右侧栏；日期格只展示课程数量、任务数量和完成摘要 |
| 全局当日待办弹窗 | 点击日期后按课程分组展示当天任务；展开课程后展示知识点 / 二级任务 |
| 本课程计划学习模式日历 | 从课程详情页进入，只展示当前课程计划日程 |
| 计划学习执行页 | 左侧只展示今日学习任务；讲义支持 PDF 导出，任务测试题支持 Markdown 导出 |
| 个人中心页 | 可查看账号资料；学习打卡颜色按二级任务完成比例展示 |

### 17.2 功能验收标准

| 功能 | 验收标准 |
|---|---|
| 课程管理 | 可创建、编辑、删除课程；只能访问自己的课程 |
| 资料管理 | 可上传文件、查看解析状态、重试失败资料；历史链接资料仅保留查看与删除 |
| Agent 问答 | 可基于课程资料回答；有引用来源；无命中时明确说明 |
| 保存为笔记 | 点击保存后生成 `AIGeneratedContent.content_type = note` |
| 课程自测 Quiz | 可生成题目、作答、查看解析和实际生成资料范围；不伪造逐题引用 |
| Flashcard | 可查看正反面、切换卡片、标记掌握状态 |
| Mindmap | 可展示节点层级关系，节点可展开收起 |
| 复习提纲 | 可生成章节化提纲并展示实际生成资料范围 |
| 知识点清单 | 可展示知识点、定义、重要程度和实际生成资料范围 |
| 学习计划 | 本期只支持单课程计划；多个计划可在首页今日待办和首页大日历合并展示 |
| 任务讲义 | 学习类二级任务可按需生成讲义，正文包含来源说明，可导出 PDF，不承诺逐段引用 |
| 任务测试题 | 测试类二级任务进入后再生成；提交单题后展示该题合法来源，并可导出 Markdown |
| 学习打卡颜色 | 根据当日二级任务完成比例显示颜色深浅 |

### 17.3 流程验收标准

| 流程 | 验收标准 |
|---|---|
| 课程创建流程 | 首页打开创建课程弹窗，提交后进入课程详情页 |
| 建课后上传资料流程 | 课程创建成功后在详情页选择资料；上传成功后进入解析流程，失败可重试且不回滚课程 |
| 课程资料问答流程 | 上传并解析资料后，Agent 可回答并展示引用来源 |
| 学习辅助生成流程 | 选择学习辅助功能后可生成内容并保存记录 |
| 学习计划生成流程 | 自然语言输入、配置回填、计划预览、保存计划完整可用 |
| 本课程计划学习模式流程 | 保存计划后可进入本课程计划学习模式日历，点击日期查看本课程知识点 |
| 首页大日历查看流程 | 首页大日历按日期聚合展示所有课程任务摘要 |
| 全局当日待办流程 | 点击首页大日历日期打开全局当日待办弹窗，按课程分组展示当天任务 |
| 计划学习执行流程 | 点击任务进入执行页，完成二级任务后同步状态 |
| 学习打卡颜色流程 | 二级任务完成比例变化后，个人中心学习打卡颜色随之变化 |

### 17.4 异常验收标准

| 异常 | 验收标准 |
|---|---|
| 登录失败 | 展示错误提示，不进入首页 |
| 登录失效 | 自动跳转登录页 |
| 无权限访问 | 阻止访问并提示无权限 |
| 资料解析失败 | 资料标记失败并可重试 |
| Agent 无资料命中 | 明确提示当前课程资料中未找到直接答案 |
| Agent 生成失败 | 保留问题，允许重试 |
| 保存计划失败 | 保留计划预览，允许重试 |
| 当日无任务 | 全局当日待办弹窗展示空状态 |
| 本课程计划不存在 | 返回课程详情页并提示计划不存在 |
| PDF 导出失败 | 内容仍可查看，导出可重试 |
| 任务状态更新失败 | 不误更新完成状态和学习完成比例 |

### 17.5 埋点验收标准

1. 核心页面浏览事件能正常上报。
2. 创建课程、上传资料、Agent 提问、生成内容、保存计划、完成任务、导出 PDF 等核心操作都有埋点。
3. 失败事件包含 `error_code`。
4. 生成类事件包含耗时字段。
5. 埋点不包含密码、完整资料内容、完整用户问题正文等敏感信息。
6. 学习完成记录相关埋点包含 `completion_ratio` 和 `color_level`。

## 18. 上线与版本说明

### 18.1 上线范围

本期上线范围：

1. 账号密码登录与注册。
2. 首页、课程管理、课程详情页。
3. 创建课程后进入课程详情页并明确引导上传资料；上传失败不回滚课程且可重试。
4. 资料解析、资料预览和引用来源定位。
5. Agent 问答、对话记录、保存为笔记。
6. 课程自测 Quiz、Flashcard、Mindmap、复习提纲、知识点清单。
7. 单课程学习计划生成、自然语言配置回填、计划保存。
8. 首页今日待办、首页大日历、全局当日待办弹窗、本课程计划学习模式日历。
9. 计划学习执行页、今日讲义、任务测试题、讲义 PDF 与测试题 Markdown 导出。
10. 个人中心与按完成比例展示的学习打卡颜色。

本期不上线范围：

1. 多课程联合生成一个学习计划。
2. 复杂社区、分享、协作功能。
3. 强制移动端完整适配。
4. 复杂间隔复习算法。
5. 外部互联网作为默认回答来源。

### 18.4 风险与回退方案

| 风险 | 影响 | 回退 / 降级方案 |
|---|---|---|
| 资料解析失败率高 | Agent 无法基于资料回答 | 允许资料重试；提示用户更换文件；临时限制复杂格式 |
| Agent 服务不稳定 | 问答和生成失败 | 保留输入和失败状态；允许重试；必要时关闭生成入口 |
| 学习计划生成质量不稳定 | 用户计划不可用 | 允许用户手动调整配置和重新生成 |
| 导出失败 | 用户无法导出讲义 PDF 或任务测试题 Markdown | 保留页面内容；导出入口提示稍后重试 |
| 首页大日历任务聚合异常 | 用户看不到计划任务 | 首页今日待办和本课程计划学习模式日历保留，作为跳转兜底 |
| 学习完成比例计算异常 | 个人中心展示不准确 | 保留任务完成状态；重新计算 CheckinRecord |
| 权限漏洞 | 数据泄露风险 | 立即关闭相关接口或加强权限校验后重发 |
| 数据半保存 | 前端展示异常 | 后端补偿修复；对外隐藏异常状态数据 |
