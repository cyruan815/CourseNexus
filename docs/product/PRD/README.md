## 文档包说明

本文档包是「CourseNexus 课枢」PRD 的 v0.3 版本。

也就是说，v0.3 不是重新设计一套目录，而是把以下标准结构按连续章节拆开：

## 拆分原则

1. 章节编号必须保持标准 PRD 的 1-19 编号，不重新编号。
2. 每个文件承接一段连续章节，不能把同一章拆散到多个不相关文件中。
3. 文件拆分是为了降低单文档长度，不改变原 PRD 结构。
4. 后续引用章节时，仍使用原始章节编号，例如“见 11.3 课程详情页”。
5. 每个文件开头需要说明本文件覆盖哪些章节。
6. Mermaid 流程图直接写在对应章节中，不单独改成图片。
7. 字段、异常、验收等后端落地内容要放在标准结构对应章节内，不额外发散成另一套目录；RESTful API 明细不在本 PRD 展开，后续放入架构 / 开发文档。

## v0.3 需要保持的关键产品口径

1. 本期用户角色只有学生用户。
2. 登录方式采用账号和密码登录；注册成功后自动登录并进入首页。
3. 系统需要真实数据库，不只是静态原型或本地假数据。
4. 课程是资料、问答、生成内容、计划和任务的基础归属对象。
5. 新建课程时资料不是必填项，但允许同步选择文件；链接资料入口已停止支持，仅保留历史记录查看与删除。
6. 资料上传成功后异步解析，解析成功后才能稳定用于检索、问答和引用来源。
7. Agent 回答必须尽量基于课程资料，并展示资料名、页码或页序号、命中文本片段。
8. 保存为笔记统一存为 `AIGeneratedContent.content_type = note`，不单独建 Note 对象。
9. 学习计划本期只支持单课程计划，不支持一个计划绑定多门课程。
10. 学习计划只在课程详情页内创建；有学习计划的课程可从课程详情页进入本课程计划学习模式日历。
11. 多门课程的多个单课程计划可以在首页今日待办和首页大日历中按日期合并展示。
12. 首页今日待办和首页大日历只负责全局查看与跳转，不提供创建、编辑或重新生成学习计划入口。
13. 首页大日历页本身只展示大尺寸月历，不默认展示右侧计划详情栏；点击日期后按课程分组展示当日待办。
14. 计划执行页左侧只展示今日学习任务，不展示整个计划树。
15. 今日讲义按需生成，支持导出 PDF。
16. 任务测试题进入任务测试题页面 / 视图后按需生成，支持导出 Markdown；测试题 PDF 导出为后续能力。
17. 资料预览不采用固定右侧抽屉，用户可选择中间分屏或小窗。

## 写作约定

1. 所有流程图使用 Mermaid 代码块。
2. 所有表格字段尽量写清：字段名、类型、是否必填、说明、枚举值。
3. 所有页面都要写页面目标、入口、结构、交互规则、状态、异常、埋点和验收。
4. 本 PRD 不要求展开接口文档；接口路径、请求响应、错误码等细节在后续架构 / 开发文档中统一说明。
5. 涉及 AI 生成内容时，必须写清输入、输出、上下文、保存规则、失败处理和引用来源。
6. 涉及异步任务时，必须写清状态流转、重试规则和用户提示。
7. 涉及删除操作时，必须写清软删除、关联数据处理和权限校验。
