# Planning

## 概述

本目录记录 CourseNexus 的共享规划沉淀：当前状态、实现路线图、技术债和信息处理优化计划。

它不是临时 Agent 执行草稿目录。临时插件过程、个人执行记录和 superpowers 运行产物放入 `docs/superpowers/`，该目录不进入 git。凡是需要团队共享、后续继续维护或影响路线判断的内容，应进入本目录或其他正式 docs 分区。
