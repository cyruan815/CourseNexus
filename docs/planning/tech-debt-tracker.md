# Tech Debt Tracker

## 一句话定位

本文件集中记录 CourseNexus 当前已知技术债，避免散落在聊天记录、临时计划或局部代码注释里。

## 技术债清单

| 编号 | 事项 | 影响 | 优先级 | 状态 |
| --- | --- | --- | --- | --- |
| TD-001 | 尚未实现统一错误响应和请求 ID。 | 前后端联调、日志排查和失败重试缺少稳定契约。 | 高 | 待处理 |
| TD-002 | 尚未实现真实鉴权和 `user_id` 注入。 | 业务 API 无法安全校验数据归属。 | 高 | 待处理 |
| TD-003 | 后端只有 models 和 migration，缺少 repository/service/schema 分层样板。 | 后续业务 API 容易把查询、权限和业务逻辑混在路由层。 | 高 | 待处理 |
| TD-004 | 资料解析、切片和引用定位尚未实现。 | Agent 问答和生成内容无法基于真实资料运行。 | 高 | 待处理 |
| TD-005 | 模型 provider、解析器、PDF 和文件存储 adapter 只有目录占位。 | 外部能力替换边界尚未通过代码验证。 | 中 | 待处理 |
| TD-006 | 前端只有最小应用壳，缺少路由、API client、错误态和页面布局基线。 | 真实页面开发前缺少统一交互和数据请求模式。 | 中 | 待处理 |
| TD-007 | SQLite 本地库已可迁移，但尚未形成数据库 reset/seed/dev data 规范。 | 多人本地调试时初始数据和迁移状态容易不一致。 | 中 | 待处理 |
| TD-008 | 生成内容 `content_json` 结构已在文档中定义，但没有 schema 校验代码。 | 模型输出结构可能漂移，前端渲染和后续导出会不稳定。 | 中 | 待处理 |
| TD-009 | 缺少后台任务或任务状态执行器。 | 资料解析、模型生成、PDF 导出等长耗时能力只能同步或手工模拟。 | 中 | 待处理 |
| TD-010 | 端到端验收尚未建立。 | 后续学习闭环容易出现前后端契约偏差。 | 中 | 待处理 |

## 更新规则

- 新增、关闭或拆分技术债时更新本表。
- 技术债影响产品范围、模块边界或数据契约时，同步更新对应正式文档分区。
- 关闭技术债时记录关闭方式，不只删除条目。
