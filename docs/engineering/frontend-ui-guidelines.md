# Frontend UI Guidelines v0.1

## 1. 定位

CourseNexus 前端 UI 是面向大学生的多课程学习工作台。它的第一目标不是展示品牌、制造视觉冲击或追求营销转化，而是帮助学生把课程、资料、问答、生成内容和学习计划组织成清晰、可追踪、可执行的学习路径。

视觉方向采用亮色系统，不使用黑色 AI 科技风。整体基调是：

```text
清晨书桌风 + 薄荷实验室风 + 学院笔记风 + 日程工作台风
```

四个方向的分工：

| 场景 | 风格 | 作用 |
| --- | --- | --- |
| 全局页面、首页、课程工作台 | 清晨书桌风 | 提供清爽、低压力、长期可用的基础体验。 |
| 认证入口、登录、注册 | 清晨书桌风 + 蓝绿入口视觉 | 提供轻量品牌识别和进入工作台的第一步，不扩展成营销落地页。 |
| AI / 资料 / 解析相关区域 | 薄荷实验室风 | 表达资料处理、检索、解析和 AI 辅助的轻科技感。 |
| 生成内容 / 引用 / 知识点 | 学院笔记风 | 表达可阅读、可引用、可复习的学习内容。 |
| 计划 / 任务 / 日历 / 执行 | 日程工作台风 | 表达任务推进、进度、时间和执行状态。 |

## 2. 设计原则

1. **工作台优先**：页面要适合反复打开、快速扫描和连续操作，不做大面积营销 hero。公开认证入口和 onboarding 可以使用克制的居中品牌入口，但只承担进入工作台的任务。
2. **亮色克制**：背景使用浅色；高饱和色只用于状态、重点或模块识别，不铺满工作台页面。登录 / 注册页左侧视觉区可以使用蓝绿渐变，但右侧表单区保持白底和高可读性。
3. **信息可追踪**：资料、引用、生成内容和计划任务必须能让用户理解来源、状态和下一步动作。
4. **组件一致**：按钮、卡片、徽标、列表、表单、弹窗在不同页面保持同一套圆角、边框、阴影和间距规则。
5. **AI 不神秘化**：AI 相关区域使用“资料解析、引用、生成状态、重试”等可解释界面，不使用黑盒科技感装饰。
6. **默认完整状态**：每个核心模块必须设计 loading、empty、error、ready 和 pending 状态。

## 4. 字体和排版

### 4.1 字体族

默认使用系统字体，避免引入额外字体依赖：

```css
font-family:
  system-ui,
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  sans-serif;
```

数字、状态码、日期和 ID 可使用等宽字体：

```css
font-family:
  "SFMono-Regular",
  Consolas,
  "Liberation Mono",
  monospace;
```

### 4.2 字号层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Page title | 28px | 700 | 1.2 | 页面标题，如课程工作台。 |
| Section title | 20px | 650 | 1.3 | 模块标题，如资料区、问答区。 |
| Card title | 16px | 650 | 1.4 | 课程名、资料名、计划名。 |
| Body | 14px | 400 | 1.6 | 正文、描述、回答内容。 |
| Meta | 12px | 500 | 1.4 | 时间、状态、辅助说明。 |

不要使用超大海报标题作为 App 工作台页面主视觉。可以在空状态、onboarding 或公开认证入口中有限使用更大的标题，但不得影响工作台信息密度。

认证入口排版规则：

- 入口页主标题可以使用展示字号，桌面端上限约 104px，移动端收敛到约 48px。
- 登录 / 注册左侧视觉区标题可以使用较大字号，桌面端上限约 76px。
- 登录 / 注册右侧表单标题保持 26px 左右，不使用海报标题。

## 5. 间距和布局

### 5.1 间距 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `space.xs` | 4px | 图标与文字、小型 badge 内部间距。 |
| `space.sm` | 8px | 表单字段内联间距、紧凑列表。 |
| `space.md` | 12px | 卡片内部小组间距。 |
| `space.lg` | 16px | 常规卡片内边距、按钮组间距。 |
| `space.xl` | 24px | 页面模块间距。 |
| `space.2xl` | 32px | 大区块分隔、页面主内容上下间距。 |

### 5.2 页面布局

- 页面背景使用 `background.page`。
- 主内容区域建议最大宽度控制在 1200px 到 1360px。
- 首页和课程详情页可采用左侧课程/模块导航 + 中央工作区 + 右侧状态栏的工作台布局。
- 认证入口页可采用顶部导航 + 居中品牌入口布局；主按钮文案使用 `开始`。
- 登录 / 注册页可采用左侧蓝绿渐变视觉区 + 右侧白色表单区的左右布局，桌面端比例约为 `2fr / 1fr`，移动端上下堆叠。
- 资料、问答、生成内容、计划等模块在课程详情页中应清晰分区，不混成一个长表单。
- 移动端优先堆叠，隐藏次级侧栏，将详情和操作放入 Drawer / Modal。

## 6. 组件规则

### 6.1 卡片

- 默认背景 `background.surface`。
- 默认圆角 8px。
- 默认边框 `1px solid border.default`。
- 默认阴影轻微，不使用强发光阴影。
- 卡片内边距 16px 或 20px。
- 课程、资料和计划卡片允许使用 3px 到 4px 的顶部或左侧状态色条。

### 6.2 按钮

- 主操作使用 `brand.primary`。
- 认证入口和登录 / 注册主按钮使用 `brand.primary`，圆角可使用 6px，允许轻微蓝色阴影表达主动作。
- 资料 / AI 处理操作可使用 `lab.mint`。
- 危险操作使用红色，并优先放在二级菜单或确认弹窗中。
- 按钮文字使用明确动词：`上传资料`、`开始解析`、`重试解析`、`生成提纲`、`保存计划`。
- 不使用模糊按钮文案，例如 `提交`、`确认一下`、`OK`。

### 6.3 Badge 和状态

资料解析状态推荐映射：

| 状态 | 文案 | 颜色 |
| --- | --- | --- |
| `uploaded` | 待解析 | warning |
| `parsing` | 解析中 | info |
| `parsed` | 已解析 | success |
| `parse_failed` | 解析失败 | error |
| `deleted` | 已删除 | neutral |

生成状态推荐映射：

| 状态 | 文案 | 颜色 |
| --- | --- | --- |
| `pending` | 等待生成 | warning |
| `running` | 生成中 | info |
| `success` | 已生成 | success |
| `failed` | 生成失败 | error |

未知状态必须有兜底样式，不让页面崩溃。

### 6.4 表单

- 表单字段按任务顺序排列，不按数据库字段顺序排列。
- 必填字段标记清楚。
- 错误提示写明修复方式。
- 长表单优先分组，不在一个卡片里堆过多字段。
- 登录 / 注册页输入框采用白底、`1px solid #DADCE0`、4px 圆角的方框样式，避免胶囊输入框。
- 登录 / 注册页辅助链接中，提示语使用灰色，真正可点击部分使用链接色。例如 `已有账户？` 为灰色，`去登录` 为链接色。

### 6.5 弹窗和抽屉

- 简短确认使用 Modal。
- 右侧详情、资料范围选择、引用详情使用 Drawer。
- Modal / Drawer 标题必须说明用户正在处理的对象。
- 删除、覆盖、重试等操作必须明确后果。

## 7. 场景规范

### 7.1 全局和课程工作台：清晨书桌风

适用范围：

- 首页
- 课程列表
- 课程详情整体框架
- 个人中心

设计要求：

- 使用浅蓝灰背景和白色卡片。
- 信息组织清楚，减少装饰。
- 课程卡片突出课程名、学期、教师、最近资料和进度。
- 不使用大面积插画或营销口号。

### 7.1.1 认证入口、登录和注册：蓝绿入口视觉

适用范围：

- 入口页 `/welcome`
- 登录页 `/login`
- 注册页 `/register`

设计要求：

- 入口页使用白色到浅蓝灰背景，并保留左上角绿色渐变光感。
- 入口页采用顶部导航 + 居中品牌内容，主动作只有一个 `开始`。
- 入口页允许使用蓝、青、紫色的低透明度全屏 Canvas 粒子场；粒子以平滑跟随鼠标的共享中心形成延伸至视口外的近圆形放射场，每颗粒子使用独立弹簧参数和局部运动相位，并叠加较强的全局径向呼吸，产生协同外扩、内收和不同步的轻微漂移，但不得拦截指针事件、遮挡正文或扩展到登录页、注册页和登录后的工作台。
- 粒子数量必须随视口面积设定上下限，高分屏像素比应限幅；系统启用 `prefers-reduced-motion: reduce` 时只渲染静态粒子，并在页面隐藏或组件卸载时停止动画和清理监听器。
- 登录 / 注册页采用左右布局：左侧蓝绿渐变视觉区，右侧白色表单区。
- 登录 / 注册表单不放进重卡片；表单区域保持白底、窄宽度、清晰标签和方框输入框。
- 登录 / 注册真实接入后必须有 pending 和 error 状态；静态原型阶段可以不展示这些状态。
- 认证入口可以有品牌识别，但不得扩展成营销型长页面，不展示课程资料、问答或计划正文。

### 7.2 AI / 资料 / 解析：薄荷实验室风

适用范围：

- 资料上传
- 资料列表
- 解析状态
- RAG 检索
- 资料范围选择器

设计要求：

- 使用薄荷青作为模块识别色。
- 解析、索引、检索状态要可解释。
- 展示资料名时使用 `name` 字段，不从 `file_url` 推导。
- 解析失败要给出重试入口和错误状态。
- AI 处理过程不做神秘黑盒动画，优先展示进度、状态和来源。

### 7.3 生成内容 / 引用 / 知识点：学院笔记风

适用范围：

- 课程问答回答区
- 引用来源
- Flashcard / Mindmap / Quiz / Outline / Knowledge List 结果
- 知识点清单和复习提纲

设计要求：

- 使用靛蓝作为内容结构色，橙色作为引用或重点标注。
- 引用来源像脚注或旁注，必须显示材料名和命中片段。
- `answer_type = no_source` 时不得展示伪引用。
- 生成内容可以有轻微纸张感，但不做旧纸复古风。
- 内容展示优先可读性，不优先炫酷动效。

### 7.4 计划和任务：日程工作台风

适用范围：

- 学习计划预览
- 学习计划列表和详情
- 今日待办
- 大日历
- 学习执行页

设计要求：

- 使用蓝色和紫色表达计划、任务和流程。
- 时间、任务状态和进度必须清楚。
- 计划任务结构优先用列表、时间线、分组卡片和进度条。
- 不在计划保存阶段展示今日讲义或任务测试题正文，遵守后端模块边界。

## 8. 空状态、加载和错误

### 8.1 Loading

- 用 Skeleton 或 LoadingOverlay 表示正在加载。
- 长耗时操作必须说明正在做什么，例如 `正在解析资料...`、`正在生成提纲...`。

### 8.2 Empty

空状态要提供下一步动作：

- 没有课程：`创建第一门课程`。
- 没有资料：`上传资料` 或 `添加资料链接`。
- 没有问答：`选择资料后开始提问`。
- 没有计划：`生成学习计划`。

### 8.3 Error

- 错误文案要说明发生了什么和如何恢复。
- 前端逻辑只根据稳定 `error.code` 判断，不解析后端中文 `message`。
- `UNAUTHORIZED` 必须清理本地 token 并回到登录态。

## 9. 禁止事项

- 禁止黑色 AI 科技风作为主界面。
- 禁止大面积紫蓝渐变作为默认背景。认证页允许使用已确认的蓝绿渐变视觉区，但不得用于工作台默认背景。
- 禁止玻璃拟态、发光边框、粒子背景、装饰性光斑作为工作台主视觉。
- 禁止把 App 页面做成营销落地页。
- 禁止把 UI 状态只做 happy path。
- 禁止没有真实引用时展示假引用。
- 禁止每个模块使用完全不同的圆角、阴影、字体和颜色规则。
- 禁止为了视觉效果降低资料名、状态、引用和任务内容的可读性。

## 10. 与 Mantine 的使用关系

- 优先使用 Mantine 原生组件搭建页面。
- 主题和二次封装应服务本规范，不为了“看起来像 Mantine 默认模板”而保留默认样式。
- 常用组件映射：

| 场景 | Mantine 组件 |
| --- | --- |
| 页面布局 | `AppShell`、`Container`、`Grid`、`Stack`、`Group` |
| 卡片和模块 | `Card`、`Paper`、`Divider` |
| 状态 | `Badge`、`Alert`、`Progress`、`Skeleton`、`LoadingOverlay` |
| 表单 | `TextInput`、`Textarea`、`Select`、`NumberInput`、`DatePickerInput` |
| 操作 | `Button`、`ActionIcon`、`Menu`、`Modal`、`Drawer` |
| 通知 | `Notification`、`Notifications` |
| 导航和分区 | `Tabs`、`Breadcrumbs`、`NavLink`、`SegmentedControl` |

## 11. 第一阶段落地顺序

当前前端应优先按后端能力接入真实工作流：

0. 认证入口和登录 / 注册：入口页、登录、注册、真实 auth API、成功进入系统首页。

1. 资料工作台：列表、上传、解析状态、重试、删除。
2. 资料范围选择器：全选已解析资料、选择部分资料、过滤不可用资料。
3. 课程问答面板：提问、追问、引用、无来源状态。
4. 生成内容面板：列表、生成入口、占位结果展示。
5. 学习计划预览和保存：目标、日期、每日时长、任务预览、保存。

每个页面或模块完成后，必须运行：

```powershell
pnpm frontend:test
pnpm frontend:build
```

如果 Codex 沙盒在 Windows 下出现 `esbuild spawn EPERM`，使用提权运行验证命令，并在结果中说明这是环境权限问题。
