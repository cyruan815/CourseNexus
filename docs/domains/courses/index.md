# Courses Domain

## 概述

课程领域负责系统首页的课程工作台和后续课程管理能力。当前实现已经从静态 POC 进入前端接入阶段：首页保留已确认的工作台视觉，但右侧课程概览改为读取后端课程列表接口；今日待办和日历因后端聚合接口尚未定义，仍展示无计划占位，不提供计划创建或生成入口。

## 业务目标

- 帮助学生进入系统后快速看到课程、今日学习任务和日历计划状态。
- 在无学习计划聚合数据时展示清晰空态，不展示不存在的任务内容或计划创建入口。
- 为后续课程详情、课程创建、学习计划生成和大日历页面保留清晰入口。

## 当前范围

- 已实现：首页工作台，包含顶部品牌栏、单按钮主题切换、个人中心待接入入口、今日计划中心、日历空状态、后端课程列表、学期筛选、课程卡片网格和添加课程入口。
- 已实现：课程列表通过 `GET /api/v1/courses` 读取当前登录用户课程，并覆盖 loading、empty、error 和 ready 状态。
- 已实现：首页课程创建、编辑和删除接入当前后端课程 CRUD 接口：`POST /api/v1/courses`、`PATCH /api/v1/courses/{course_id}`、`DELETE /api/v1/courses/{course_id}`。创建成功后进入新课程详情页并触发课程详情页上传资料弹窗；编辑成功后留在首页并更新卡片；删除前二次确认，成功后从首页列表移除。
- 未实现：创建课程弹窗内同步添加初始资料、资料数量聚合、今日任务聚合、计划生成页跳转、大日历页。

## 模块边界

- `HomePage` 只负责挂载课程首页工作台。
- `features/courses/HomeWorkbench.tsx` 承载首页 UI 状态、课程列表接入、创建课程弹窗、编辑课程弹窗和删除确认弹窗，通过 `features/courses/api.ts` 的课程 CRUD adapter 访问后端。
- 首页课程卡片只消费 `CourseRead` 中已有的课程字段；资料数量、今日任务数量和计划进度在对应后端聚合接口落地前不伪造统计。
- 今日待办、日历和学习计划的真实状态属于 `study-mode` / `todos-calendar` 相关领域；课程首页只能展示聚合结果，不直接耦合其内部实现。

## 状态流转

当前首页状态：

- 课程概览 loading：显示课程加载文案和课程卡片骨架。
- 课程概览 ready：展示后端返回的当前用户课程，课程详情链接使用后端课程 `id`。
- 课程概览 empty：后端返回空列表时展示“还没有课程”和添加课程入口。
- 课程概览 error：展示后端错误文案和“重试加载课程”按钮，不回退到 mock 课程。
- 创建课程：点击添加课程入口打开弹窗；课程名称必填，简介、教师可选，学期通过前端固定选项选择或清空；提交时调用 `POST /api/v1/courses`，pending 时禁用重复提交；成功后使用返回的课程 `id` 跳转到 `/courses/{id}`，并通过路由 state 请求课程详情页自动弹出上传资料提示；失败时保留表单并展示错误。
- 编辑课程：课程卡片更多菜单打开编辑弹窗；保存时调用 `PATCH /api/v1/courses/{course_id}`；成功后在当前首页列表中替换该课程卡片，不跳转；失败时保留表单并展示错误。
- 删除课程：课程卡片更多菜单打开删除确认弹窗；确认后调用 `DELETE /api/v1/courses/{course_id}`；成功后从首页列表移除该课程；失败时不移除卡片并展示错误。
- 今日待办：在后端计划聚合接口落地前只展示无计划占位，不展示具体课程任务、任务数量或计划生成入口。
- 日历：展示当前月份空日历，不展示虚构任务圆点或任务日期。

后续接入真实接口时需要补齐：

- loading：今日任务和日历聚合加载中。
- empty：没有计划、当天没有任务。
- error：计划聚合加载失败，提供重试入口。
- ready：展示真实计划聚合。
- 今日待办接入后必须按后端状态互斥展示：无计划时只展示空态提示；有待办时展示待办列表和状态；全部完成时展示完成状态；不能同时展示概念态里的多个示例状态。

## 关键决策

- 首页采用 Mantine 组件和局部 CSS，遵守亮色工作台规范，不做营销型 hero。
- 左侧计划区域比课程区更窄，但通过今日计划中心和日历上下铺满形成页面视觉重心；右侧课程区保持扫描友好的课程信息卡。
- 静态数据放在 `HomeWorkbench.tsx` 内部，避免在尚未确认 API 聚合契约前扩大数据层变更。
- 课程名是明确链接，卡片更多操作是独立按钮，避免交互元素嵌套。
- 主题切换已具备前端功能骨架，会把浅色 / 深色模式写入本地存储并标记到 `documentElement`，当前只做基础配色，后续视觉优化时再细调。个人中心入口仍为待接入禁用态。首页不提供学习计划创建、编辑或重新生成入口。
- 创建课程弹窗当前只创建课程基础信息，不在弹窗内同步上传初始资料；资料上传仍通过课程详情页资料工作台处理。首次创建成功进入课程详情页时，前端会自动弹出可关闭的上传资料提示，引导用户继续上传资料但不阻塞课程创建结果。
- 首页课程卡片整体可点击进入课程详情页；课程卡片更多操作按钮独立处理编辑和删除，不触发课程详情跳转。
- 学期字段前端先使用固定下拉选项，当前选项为 `2025-2026 春季`、`2025-2026 秋季`、`2026-2027 春季`、`2026-2027 秋季`；历史课程学期会在展示和筛选时尽量规范化为同一格式，后续若后端提供学期枚举或校验，应以统一契约为准。
- 课程卡片颜色使用固定调色板按课程顺序循环分配，当前顺序为 `blue -> mint -> indigo -> violet -> orange`，保证相邻课程颜色不同；后续创建课程时如果后端不提供颜色字段，前端可按列表排序索引使用同一规则兜底。
- 后端课程对象当前没有课程颜色、资料数量、今日任务数量或首页计划进度字段；首页只按课程列表顺序兜底颜色，并用“资料待接入 / 今日任务待接入”明确标记尚未接入的聚合能力。

## 已知限制

- 本页面已读取真实课程列表，并接入课程创建、编辑和删除；但仍不读取真实计划或日历聚合数据。
- 创建课程弹窗不再承载初始资料上传；当前实现改为创建成功后进入课程详情页并自动弹出可关闭的上传资料提示。PRD 中“创建时可选添加初始资料 / 链接”的原始口径如需长期调整，应同步更新产品文档。
- 主题切换按钮已接入前端本地状态；个人中心按钮尚未绑定行为，当前以待接入禁用态展示。
- 课程详情链接已使用后端课程 id。
