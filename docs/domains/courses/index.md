# Courses Domain

## 概述

课程领域负责系统首页的课程工作台和后续课程管理能力。当前实现已经从静态 POC 进入前端接入阶段：首页保留已确认的工作台视觉，但右侧课程概览改为读取后端课程列表接口；今日待办和日历因后端聚合接口尚未定义，仍展示无计划占位，不提供计划创建或生成入口。

## 业务目标

- 帮助学生进入系统后快速看到课程、今日学习任务和日历计划状态。
- 在无学习计划聚合数据时展示清晰空态，不展示不存在的任务内容或计划创建入口。
- 为后续课程详情、课程创建、学习计划生成和大日历页面保留清晰入口。

## 当前范围

- 已实现：首页工作台，包含顶部品牌栏、单按钮主题切换占位、个人中心占位、今日计划中心、日历空状态、后端课程列表、学期筛选、课程卡片网格和添加课程入口。
- 已实现：课程列表通过 `GET /api/v1/courses` 读取当前登录用户课程，并覆盖 loading、empty、error 和 ready 状态。
- 未实现：课程创建表单、资料数量聚合、今日任务聚合、计划生成页跳转、大日历页、课程卡片编辑/删除菜单。

## 代码入口

- 课程列表旧组件仍保留在：`frontend/src/features/courses/CourseList.tsx`

## 模块边界

- `HomePage` 只负责挂载课程首页工作台。
- `features/courses/HomeWorkbench.tsx` 承载首页 UI 状态和课程列表接入，通过 `features/courses/api.ts` 的 `listCourses()` 获取课程数据。
- 首页课程卡片只消费 `CourseRead` 中已有的课程字段；资料数量、今日任务数量和计划进度在对应后端聚合接口落地前不伪造统计。
- 今日待办、日历和学习计划的真实状态属于 `study-mode` / `todos-calendar` 相关领域；课程首页只能展示聚合结果，不直接耦合其内部实现。

## 状态流转

当前首页状态：

- 课程概览 loading：显示课程加载文案和课程卡片骨架。
- 课程概览 ready：展示后端返回的当前用户课程，课程详情链接使用后端课程 `id`。
- 课程概览 empty：后端返回空列表时展示“还没有课程”和添加课程入口。
- 课程概览 error：展示后端错误文案和“重试加载课程”按钮，不回退到 mock 课程。
- 今日待办：在后端计划聚合接口落地前只展示无计划占位，不展示具体课程任务、任务数量或计划生成入口。
- 日历：展示当前月份空日历，不展示虚构任务圆点或任务日期。

后续接入真实接口时需要补齐：

- loading：今日任务和日历聚合加载中。
- empty：没有计划、当天没有任务。
- error：计划聚合加载失败，提供重试入口。
- ready：展示真实计划聚合。
- 今日待办接入后必须按后端状态互斥展示：无计划时只展示空态提示；有待办时展示待办列表和状态；全部完成时展示完成状态；不能同时展示概念态里的多个示例状态。

## 关键决策

- 首页采用 Mantine 组件和局部 CSS，遵守亮色工作台规范，不做营销型 hero。
- 左侧计划区域比课程区更窄，但通过今日计划中心和日历上下铺满形成页面视觉重心；右侧课程区保持扫描友好的课程信息卡。
- 静态数据放在 `HomeWorkbench.tsx` 内部，避免在尚未确认 API 聚合契约前扩大数据层变更。
- 课程名是明确链接，卡片更多操作是独立按钮，避免交互元素嵌套。
- 当前添加课程、主题切换和个人中心入口只做静态占位；主题按钮按当前模式仅展示可切换到的目标模式图标。首页不提供学习计划创建、编辑或重新生成入口。
- 课程卡片颜色使用固定调色板按课程顺序循环分配，当前顺序为 `blue -> mint -> indigo -> violet -> orange`，保证相邻课程颜色不同；后续创建课程时如果后端不提供颜色字段，前端可按列表排序索引使用同一规则兜底。
- 后端课程对象当前没有课程颜色、资料数量、今日任务数量或首页计划进度字段；首页只按课程列表顺序兜底颜色，并用“资料待接入 / 今日任务待接入”明确标记尚未接入的聚合能力。
