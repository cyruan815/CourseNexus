# Domains

## 概述

本目录是未来功能模块知识库入口，用于沉淀稳定的领域知识、业务术语、状态流转和跨模块规则。

当前 v0.1 阶段不提前创建具体模块目录。具体模块文档将在项目基座框架完成、模块分工确认后创建。

## 维护规则

- 当前阶段不得提前创建具体模块目录。
- 只有模块负责人确定、模块进入实际开发、模块边界稳定、API 或数据契约需要独立维护时，才创建具体模块文档。
- 未来每个模块目录建议包含 `index.md`、`model.md`、`api.md`、`rules.md`。
- 模块文档必须与全局模块边界、API / 数据契约和 PRD 保持一致。
- 不得把临时实现细节写成长期领域规则。
