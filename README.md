# CourseNexus 课枢

CourseNexus 课枢是一个面向大学生多课程学习场景的 Agent 学习助手平台。

系统围绕课程资料构建学习工作台，支持课程管理、资料上传与解析、课程资料问答、知识点整理、学习计划生成、今日待办、首页大日历、闪卡、思维导图、课程自测和任务测试题等能力，帮助学生把分散资料转化为可追溯、可执行的学习路径。

推荐仓库名：`course-nexus`

## Project Status

当前仓库处于 PRD 阶段，需求文档位于 [PRDV0.3](./PRDV0.3)。

## Core Capabilities

- 多课程管理与课程资料管理
- 基于课程资料的 Agent 问答和引用来源追溯
- 复习提纲、知识点清单、课程自测、Flashcard、Mindmap 生成
- 单课程学习计划生成与课程内计划学习模式
- 首页今日待办与首页大日历聚合跳转
- 今日讲义、任务测试题和 PDF 导出
